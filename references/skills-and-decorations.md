# MHS3 Skills & Decorations Reference

## Skill Sources

Skills come from three places in MHS3:

1. **Weapons** — Each weapon has built-in skills (weapon-specific attacks + passive effects)
2. **Armor** — Each armor set provides passive skills for the Rider
3. **Genes** — Monstie gene grid skills (see `genes-and-builds.md` for full gene skill list)
4. **Decorations** — Slotted into deco slots on weapons and armor

Weapon/armor skills affect the **Rider**. Gene skills affect the **monstie**. They are separate systems.

## Decoration System

- Weapons and armor have **0–3 decoration slots**
- Decorations are crafted or found, and slot into empty deco slots
- Decorations provide additional passive skills to the Rider
- Higher-tier decorations provide stronger effects
- Decorations can be freely swapped between equipment

## Skill Tiers

Skills come in tiers: **(S) < (M) < (L) < (XL)**. Higher tiers have stronger effects.
Same-name skills from different sources do NOT stack — only the highest tier applies.

## Weapon Skill Types

Weapon skills are primarily **active attacks** specific to each weapon type. See the per-type weapon files for full skill lists per weapon. Common weapon skill categories:

- **Mastery skills** (GS/LS/Hammer/HH/Bow/GL Mastery) — boost damage for that weapon type
- **Counter/Stance skills** (Retaliation Stance, Lunge Stance) — reactive attacks
- **Burst skills** (Charge Burst, Spinning Meteor, Magnificent Trio) — high-damage finishers
- **Support skills** (Mending Musician, Soothing Song) — Hunting Horn healing/buffs

## Affinity Suffixes on Weapon Skills

Weapon skills show affinity suffixes like (STR), (ATK), (FLSH), etc. These are trade-off modifiers.
For the full affinity effects table, see `genes-and-builds.md` — the system is identical for weapon and gene skills.

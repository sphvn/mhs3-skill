# Monsties — MHS3

88 hatchable companion monsters. P=Power, S=Speed, T=Technical. Ranks 1–7. Regions: Az=Azuria, Ca=Canalta, Ta=Tarkuan, Se=Serathis, PG=Post-game.

For the full table by species: [species-guide.md](species-guide.md). For individual base stats + bingo bonuses: `grep "^{Name}|" monsties/monsties.psv`.

## Tier List (Game8, updated April 7, 2026)

Search flag: for current meta shifts, search `game8.co/games/Monster-Hunter-Stories-3/archives/586383`.

### SS Tier (best in game)

| Monstie | Type/Elem | Why |
|---|---|---|
| Espinas | P/Fire | Best status — Venom Flame (Paralysis + Noxious Poison). High HP/ATK, low stamina cost |
| Namielle | T/Water | Earliest Elder Dragon. Storm Veil grants 4 buffs (Water ATK, Thunder ATK, Wyvernfell, Def Up) |
| Malzeno | S/Dragon | Self-sustaining (Night Parasites). Nightmare Cradle = AoE Dragon + Attack Down |
| Velkhana | T/Ice | High ice damage/stam. Icicle skills apply Def Down + Accuracy Down |
| Deviljho | P/Dragon | Massive Wyvernsoul damage via Dragonblast. Dragon Eater sustain |
| Boltreaver Astalos | T/Thunder | Crit-focused DPS. Paralysis + Blue Plasma + Solar Cry |
| Brute Tigrex | P/Non-Elem | Upgrade to Purple Gypceros tree — Reverberating Roar AoE Stun |
| Magnamalo | S/Non-Elem | Blastblight burst — Hellfire Retribution. Fits any team |
| Dreadqueen Rathian | S/Fire | AoE Severe Poison + Burn. High HP/ATK. Easy to obtain |
| Ruiner Nergigante | P/Dragon | Self-healing + crit-kinship engine (top PvE endgame) |

### S Tier (excellent)

Dreadking Rathalos (P/Fire — highest ATK, Dragon weak), Arkveld (—/Dragon — self-ATK buff, Wyvernsoul Def Down), Brachydios (P/Non-Elem — Blastblight + balance), Green Nargacuga (S/Non-Elem — AoE Stun + evasion), Lunagaron (S/Ice — best ice), Purple Gypceros (P/Non-Elem — earliest Stun), Silverwind Nargacuga (S/Non-Elem — 20% base crit, White Shadow 2-turn dodge), Thunderlord Zinogre (P/Thunder — highest Thunder DPS), Ivory Lagiacrus (S/Thunder — balanced Thunder + Paralysis), Red Khezu (T/Thunder — Thunder Trap + AoE Paralysis), Bloodbath Diablos (S/Non-Elem — extreme offense, low survivability).

### A Tier (strong)

Stygian Zinogre, Deadeye Yian Garuga, Aurora Somnacanth, Azure Rathalos, Hellblade Glavenus, Grimclaw Tigrex, Lagiacrus, Soulseer Mizutsune, Astalos, Ajarakan, Diablos, Black Diablos, Nargacuga, Barioth, Rajang.

### B–D Tier

- **B (solid)**: Canyne, Zinogre, Glavenus, Legiana, Tigrex, Sand Barioth, Mizutsune, Pink Rathian, Seregios, Almudron, Ratha, Bishaten, Tobi-Kadachi.
- **C (early/niche)**: Rathalos, Gammoth, Gore Magala, Odogaron, Barroth, Royal Ludroth.
- **D (replace quickly)**: Velocidrome, Yian Kut-Ku, Arzuros, Aptonoth.

## Regional Team Recommendations (Story Progression)

### Azuria (Early)
| Monstie | Type/Elem | How to Get |
|---|---|---|
| Dreadqueen Rathian | S/Fire | Rathian/Pink Rathian Ecosystem Rank S + 3 Poison-skill monsters |
| Boltreaver Astalos | T/Thunder | Astalos Rank A + 3 Thunder monsters |
| Purple Gypceros | P/Non-Elem | Immediately available in Broadleaf Basin |

Solar Cry (Kinship Gauge +30) from Dreadqueen/Boltreaver is crucial for hard fights.

### Canalta (Mid)
| Monstie | Type/Elem | How to Get |
|---|---|---|
| Deviljho | P/Dragon | Northeast of Cataracts Camp (force retreat) |
| Deadeye Yian Garuga | S/Fire | Yian Garuga Rank S + 3 five-star+ monsters |
| Green Nargacuga | S/Non-Elem | Nargacuga Rank A Habitat Restoration |
| Aurora Somnacanth | T/Ice | Eggs in Mt. Canalta |

Deviljho + Deadeye apply Wyvernsoul Def Down → faster knockdowns.

### Tarkuan (Mid-Late)
| Monstie | Type/Elem | How to Get |
|---|---|---|
| Espinas | P/Fire | Bountiful Dunes or Secret Espinas retreat in Azuria |
| Brute Tigrex | P/Non-Elem | Tigrex Rank A any habitat |
| Ivory Lagiacrus | S/Thunder | Lagiacrus Rank A Habitat Restoration |
| Stygian Zinogre | T/Dragon | Zinogre Rank A Habitat Restoration |

Espinas's Noxious Poison = continuous damage, top-tier.

### Serathis (Late)
| Monstie | Type/Elem | How to Get |
|---|---|---|
| Deviljho | P/Dragon | Eggs in Sacrosanctum/Lazlion |
| Magnamalo | S/Non-Elem | Tigrex Rank A any habitat |
| Lunagaron | S/Ice | Eggs in Old Capital Road |
| Boltreaver Astalos | T/Thunder | Astalos Rank A + 3 Thunder |

Many late bosses weak to Dragon. Magnamalo gives Blastblight burst.

## Recommended Team Compositions

- **Balanced PvE**: Dreadqueen Rathian (S/Fire) + Boltreaver Astalos (T/Thunder) + Ruiner Nergigante (P/Dragon)
- **Elemental coverage**: Add Velkhana (Ice) or Namielle (Water)
- **PvP**: Velkhana (Skill Seal) + burst DPS + status pressure
